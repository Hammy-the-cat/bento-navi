# 学校名検索（1.4.0）

学校の位置特定と周辺店舗取得は別の処理。学校は端末内の国交省・文科省データを優先し、店舗の既存R2経路を変更しない。

## データと更新

- 国交省 P29 学校2023年度版の都道府県別GeoJSONを取得（CC BY 4.0）。
- 文科省学校コードページの最新表の全CSVを読み、学校コードごとの最新属性を採用。初期版は2026年5月時点の暫定一覧。
- 同じ学校コード・住所のみ座標を引き継ぐ。名称変更は現名称＋旧名の別名を保持。廃止・休校・住所変更・新設で位置が未確認の学校は古い座標を使わず監査へ記録。
- 47都道府県、52,808地点。圧縮1,850,952バイト。アプリは全校の必要項目だけを同梱・端末保存する。毎回全国ファイルを再取得せず、版が変わったときだけ更新。
- `tool/school_data/build.py --bundle assets/schools` で同梱版を再生成。監査は `build/schools/audit.json`。初期監査を `docs/data/school-index-audit.json` に保存。
- GitHub Actions `Update school data` は毎月2日04:17 JSTに公開元の更新を確認。欠落・異常件数で失敗した場合、既存の版を保持する。
- R2の `schools/versions/<sha256>.json.gz` を書き込み・読戻し照合後に `schools/active.json` を更新。店舗用ポインターとは独立。
- Workerは `/schools/manifest.json` とハッシュ指定データだけを配信。端末で圧縮データと展開後の両方のハッシュ・件数・座標・47都道府県を検証。保存の破損や通信障害では同梱版／前の正常版を使う。
- アプリ起動・復帰時にバックグラウンドで更新を確認（成功後は同一プロセス内で1日、失敗後は5分の間隔）。検索は更新完了を待たない。

## 検索と誤案内防止

- 半角・全角空白を扱い、「中」と「中学校」、「小」と「小学校」、「高校」と「高等学校」を照合する。
- 県名だけでなく県＋郡＋市町村を住所で確認。同名校は候補から選択する。県名を含む学校の正式名称も保持する。
- 1文字の追加・削除・置換に相当する候補は、県が指定されているときだけ提示。誤字と断定せず、1候補でも自動採用しない。
- 「深浦中 青森県西津軽郡」は深浦町立深浦中学校（40.651451,139.936082）。「青峰中 佐賀県」は伊万里市立青嶺中学校など該当候補を表示し選択を要求する。
- 索引で見つからない学校・学校以外の施設には従来の外部検索を残す。略称の学校名でも別の学校を返した応答を除外する。
- 国の位置データの基準年度以降に移転・新設された学校などは収録できない場合がある。その際は正式住所／現在地検索を利用する。

## 検証

Flutterの検索・キャッシュ・全国9地域・既存回帰テスト、Pythonの住所照合・閉校・移転・新設監査・公開保護テスト、Workerの公開ルートと異常時応答テストを実施。
実機の操作感はTestFlight更新版で確認する。既存1.3.2は学校索引を読まないため、一度アプリ更新が必要。

出典URL・加工内容はアプリの「学校データの出典」から閲覧可能。
