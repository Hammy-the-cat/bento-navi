## 4. App Review に関する情報

| 欄 | 入力内容 |
|---|---|
| サインインが必要 | **チェックを外す**（会員登録不要のアプリのため） |
| 連絡先情報 | 氏名・電話番号・`excitedcherry0909@gmail.com` |
| メモ | 下記を貼る |

メモ欄（審査担当者へのメモ）:

```
本アプリは、スポーツの遠征先で弁当を購入できる店舗を検索するアプリです。

・会員登録は不要で、すべての機能をそのままご利用いただけます。
・店舗データは OpenStreetMap のオープンデータを、Nominatim および
  Overpass API 経由で取得しています。
・位置情報は「現在地」ボタンを押したときのみ取得し、周辺店舗の検索に
  使用します。端末外に保存することはありません。
・動作確認には「県総合運動公園 宮崎」などの会場名をご入力ください。
```

> 最後の1行を入れておくと、審査担当者が検索を空振りして
> 「機能しない」と判断されるリスクを減らせる。

## 6. 価格および配信状況

左サイドバー →「価格および配信状況」

| 項目 | 設定 |
|---|---|
| 価格 | **無料** |
| 配信地域 | **日本のみ** |

⚠️ **配信地域は必ず日本のみに絞る。** EUを含めるとデジタルサービス法（DSA）の
事業者情報登録が必要になり、未登録だとEUで配信停止になる。

## 7. カテゴリ・年齢制限

「App情報」ページ

| 項目 | 設定 |
|---|---|
| プライマリカテゴリ | フード/ドリンク |
| セカンダリカテゴリ | 旅行 |

年齢制限は「編集」から質問票に答える。**すべて「なし」で 4+ になる。**

⚠️ 1問だけ注意: **「制限のないWebアクセス」は「いいえ」**。
本アプリが開くのは自サイトの記事ページとGoogleマップだけで、
任意のURLを開けるブラウザ機能は持たない。ここを「はい」にすると 17+ になる。

## 8. 提出

右上の **「審査へ提出」**。

提出時に聞かれること:

| 質問 | 答え |
|---|---|
| 輸出コンプライアンス | `Info.plist` に `ITSAppUsesNonExemptEncryption=false` があるため**聞かれない**。もし聞かれたら「暗号化を使用していない（標準的なHTTPSのみ）」 |
| 広告識別子（IDFA）の使用 | **いいえ**（v1.0に広告SDKは入っていない） |
| コンテンツ配信権 | 第三者のコンテンツを含まない |
| リリース方法 | **手動でリリース**を推奨。審査通過後、自分のタイミングで公開できる |

## 審査が通らなかった場合

想定される指摘と対応。

| 指摘 | 対応 |
|---|---|
| **4.2 最低限の機能** | 検索履歴・カテゴリ絞り込み・共有リンク・記事コンテンツがあることを返信で説明する。スクリーンショット1枚目に検索履歴が写っているのはこの対策 |
| **2.1 情報不足** | 審査メモの検索例（「県総合運動公園 宮崎」）を案内する |
| **5.1.1 位置情報の用途が不明確** | `Info.plist` の `NSLocationWhenInUseUsageDescription` に用途を明記済みである旨を伝える |

返信は App Store Connect の「解決センター」から行う。
