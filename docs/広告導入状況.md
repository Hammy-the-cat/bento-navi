## ビルドと確認

Codemagicでは `ios-admob-test` ワークフローを使用する。Googleのテスト広告枠だけを利用する。App Storeへの自動審査提出は無効。通常の `ios-release` は確認完了までガードで停止する。

ローカルの全体テスト30件・静的解析成功。その後の同意変更エラーの修正で回帰テストを1件追加し、同意関連4件成功。最終コードcommit `95a67a9` のCodemagic build `6aae8e523e1cc0f02fb5b9ce` は静的解析・全テスト・iOS署名ビルド・Appleへのアップロードに成功（5分14秒）。ビルドは **1.3.0 (15)**。旧ビルド14は修正反映のため中止した。

ビルド時には従来の起動画像がプレースホルダーとの警告あり。今回の広告コードのコンパイルにはエラーなし。IPAのローカル取得はChrome側でブロックされたため、アーカイブ内のプライバシーマニフェストの現物確認は未完了。

実機では次を確認する。

1. 起動・会場検索・現在地検索・再検索が正常。広告待ちで検索が遅延しない。
2. 検索結果の下に「広告（テスト）」が表示され、リストや地図、電話等を隠さない。
3. オフラインでも操作可能。広告が読み込めなくても検索のエラー表示や既存店舗を維持する。
4. 対象地域の同意画面で同意・拒否・変更が可能。日本では地域条件により画面が出ない場合がある。
5. iPhone縦横・小さい画面で広告がはみ出さない。
