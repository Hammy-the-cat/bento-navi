# 審査用スクリーン録画の台本

Apple から「実機での操作を映したスクリーン録画」を求められた際の撮影手順。

## 準備

- **TestFlight版のビルド `1.0.0 (11)` を使う**（AdMob削除済みの最新版）
- 撮影前に一度アプリを終了し、**位置情報の許可がまだ出ていない状態**にしておく
  （設定 → べんとうナビ → 位置情報 → 「聞く」に戻す）。位置情報の許可ダイアログが
  審査官に見えるようにするため
- Wi-Fi または電波の入る場所で撮る（検索が実際に動く様子を見せる必要がある）
- 長さの目安：**1〜2分**。短すぎず、機能が一通り伝わる長さ

## 撮影方法

1. コントロールセンターを開く（画面右上から下にスワイプ、機種により異なる）
2. 画面収録ボタン（⏺ 二重丸のアイコン）を長押し → 「べんとうナビ」等のマイクは不要なのでオフのまま → 収録開始をタップ
3. 3秒後に収録が始まる
4. 下記の手順どおりに操作
5. コントロールセンターから収録を停止（または画面上部の赤いバーをタップ）
6. 「写真」アプリに保存される

## 操作の流れ（この順で）

1. **ホーム画面からアプリを起動する**（TestFlightからではなく、ホーム画面のアイコンをタップ）
2. アプリが開き、検索画面が表示されることを見せる
3. 検索欄に **「県総合運動公園 宮崎」** など会場名を入力する
4. 検索範囲（例: 1km）を選ぶ
5. 「会場周辺を検索」をタップする
6. **位置情報を使っていないことを示すため、まずこちらを先に行う**（現在地は使わない検索）
7. 検索結果のリスト画面が表示される様子を見せる（数秒静止して画面が読めるようにする）
8. 上部の「地図」タブをタップして地図表示に切り替える
9. カテゴリのチップ（コンビニ／スーパー等）を1つタップして絞り込みを見せる
10. リストに戻り、店舗の「経路」ボタンをタップする
11. **位置情報の許可ダイアログが出る場合はここで許可する**（Googleマップへの遷移確認ダイアログが出ることもある。出たら許可／開くを選ぶ）
12. Googleマップが開いて経路が表示されることを確認したら、べんとうナビに戻る
13. 画面下部の「現在地」ボタンをタップする
14. **位置情報の使用許可ダイアログが表示される**（まだ許可していない場合）→ 「Appの使用中は許可」を選ぶ
15. 現在地周辺の検索結果が表示されることを見せる
16. フッターの「記事一覧」または「使い方」リンクをタップし、静的コンテンツページが開くことを見せる（アプリ内ブラウザで開く）
17. 戻ってアプリを閉じる

## 撮り終えたら

- 「写真」アプリから該当の動画を選び、**ファイルサイズを確認**（大きすぎる場合は「編集」で不要な前後をトリミングする）
- Resolution Center の添付サイズ上限は公式に明記されていないが、コミュニティ情報では
  **数十MB程度**とされる。1〜2分の画面収録なら収まることが多いが、念のため以下のどちらかで：
  - 動画ファイルをこのPCに送る（AirDrop・メール添付など）→ こちらでResolution Centerに添付する
  - サイズが大きい場合は Google ドライブ等にアップロードし、**共有リンクを教えてもらう**
    → 添付の代わりにリンクを本文に貼る形で提出する
